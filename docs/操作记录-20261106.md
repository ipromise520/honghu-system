### G-01　抽公共匹配模块 `app/services/broad_match.py`

- 改动前：CID 补齐只有一次性脚本 `backend/enrich_broad_user_list.py`（旧 30 列快照写死 `row[3]/row[13]/row[30]`，与新 15 列 CSV 不兼容）；责任田匹配仅在 `metrics.py::_match_territory` 用子串（装机单补处理人），两套口径均不可复用。
- 改动后：新增 `app/services/` 包与 `broad_match.py`，CID 上传确认与广义用户导入确认共用同一套规则：
  1. **CID 命中**：账号归一（去空格/全角/大写、纯数字去前导零）精确 → 清单电话（11 位手机号）兜底；命中来源写入 `cid_source` 后缀「(电话兜底)」。
  2. **只填空值**：`cid_sn` 空则填；旧 CID 来源（`cid_source` 含 “CID”）的 `cid_sn` 允许刷新；非 CID 来源不覆盖并计入 `conflict_sn`；`community` 只填空，不同值计入 `conflict_community`。
  3. **电话**：仅在清单电话为空、且账号本身为 11 位手机号时补（`phone_source` 记「CID智能网关…(账号即手机号)」）；源表电话永不覆盖。
  4. **责任人/网格**：取 `territory_responsible`（`active=1`）的 `territory` 列（小区名，`community` 列全空），归一（去空格/尾部 H/含字母转小写）后**精确相等 + 同区县**，不做子串/模糊；空填，责任田来源刷新，`owner_source='源表-当前处理人'` 不覆盖并保留 `owner_original`。
  5. **状态**：四要素（电话/SN/小区/责任人）齐全 = 已匹配；否则命中 CID 或责任田 = 部分匹配；否则 = 待正式匹配；缺口与「CID账号/电话未命中」写入 `unmatch_reason`。

### G-02　快照表 / 暂存表

- `cid_records(account_norm PK, account, cid_sn, community, district, version, source_file, updated_at)`：以归一账号为唯一键（快照语义，整表替换）。
- `cid_staging(batch_id, account_norm, account, cid_sn, community, district, row_no)` + `(batch_id, account_norm)` 索引（批量插入后再建索引，避免边插边维护）。
- 上传只写 staging；确认时**同一事务**内：`DELETE cid_records` → `INSERT OR IGNORE … SELECT … GROUP BY account_norm` → `DELETE` 该批 staging → 全量重匹配 `broad_user_list` → `commit`；异常 `rollback` 并返回 400。
- 上传前调用 sqlite3 在线 backup API 生成一致性快照（不用 `cp` 主库，避免 WAL 下拷贝不一致）。

### G-03　上传渠道（400MB 流式落盘）

- `SYNC_MODULES["cid_data"]`（「CID数据（智能网关）」），`upload` 与 `confirm` 均校验 `get_role(user) == "super_admin"`，否则 403。
- **不整读**：不再 `await up.read()`（原逻辑会把 247MB 读成 bytes + 解码，内存翻倍）；改为 `request.form()` 后直接对 `UploadFile.file`（Starlette SpooledTemporaryFile）流式 `csv.reader` 解析，`fileno()` 取字节数，> 400MB 或请求体超限 → 400/413；
- 编码 GB18030、逗号分隔；表头必需「用户上网账号 / CID上报SN / 归属小区」，缺列 400；版本号从文件名 `20\d{6}` 推导（本样例 `20260801`）；
- 每 1 万行 `executemany` 落 staging，解析完成后再建索引并做不写库的预览匹配（`enrich_broad_rows(apply=False, batch_id=…)` 直接从 staging 取值）；
- 磁盘守卫：剩余空间 < max(3×文件大小, 512MB) 直接拒绝；其它渠道仍走原解析上限（30MB）。

### G-04　前端「数据同步」新增页签
